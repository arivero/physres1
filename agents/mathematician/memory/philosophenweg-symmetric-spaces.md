# Symmetric Spaces: V_HD Constancy

## Rank-1 symmetric spaces: radial density = (sin r)^a (sin 2r)^b, alpha = (a+2b)/2
- S^d: alpha = (d-1)/2. V_HD const iff alpha(alpha-1)=0 iff d=3 (alpha=1)
- CP^n: alpha=n. Const iff n=1 (CP^1=S^2 in FS coords, alpha=1)
- HP^n: alpha=2n+1 ≥ 3. NOT constant
- CaP^2: alpha=11. NOT constant

## V_HD const in geodesic coords only for: R^d (flat), S^3, H^3, CP^1 (Fubini-Study)
V_HD constant is a COORDINATE CHART property, not intrinsic manifold property.

## Formula V_HD(const) = -(d-1)R/(4d) verified only for constant-curvature (S^d, H^d)
For other symmetric spaces, may involve additional curvature invariants.

## Paper potential: Prop "Among rank-1 symmetric spaces in geodesic polar coords,
V_HD constant only for S^3, H^3, and quotients." Possible Remark D9.1k-bis.
