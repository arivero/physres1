## §1. HC Drift-Term: Open Question Resolved

### §1.1. The status.md concern

This needs resolution. Let me examine what was claimed and what is true.

### §1.2. Three operator expressions

On compact semisimple G, acting on class functions (identified with W-anti-invariant functions
on T via the Weyl denominator):

**Expression A** (HC radial formula, Fact 3):
```
(-Δ_G f)(e^H) = D(H)^{-1} (-Δ_T)(D(H) · f(e^H))   [pointwise formula]
```
Hence as operators on L²(T, dt):
```
-Δ_G|_class = D^{-1}(-Δ_T)D     [operator identity on L²(T, dt), acting on D·f]
```

**Expression B** (expansion of conjugation):
```
D^{-1}(-Δ_T)D = -Δ_T + |ρ|² + 2∇(log D)·∇
```
This is the FULL expansion. The three terms are:
- (i) -Δ_T:   the flat toral Laplacian
- (ii) |ρ|²:  zero-order term (potential)
- (iii) 2∇(log D)·∇: first-order drift term

So D^{-1}(-Δ_T)D ≠ -Δ_T + |ρ|² (omitting drift is WRONG).

**Expression C** (half-density Laplacian on (T, D²dt)):
```
-Δ_{1/2}^{(T,D²dt)} = D^{-1}(-Δ_T)D
```
by definition of half-density Laplacian via square-root-of-density conjugation.

### §1.3. What Thm M3.1 actually claims

**Thm M3.1** (HC notebook Part 3): `-Δ_{1/2}^G|_class = -Δ_T on L²(T, D²dt)`.

This is a claim about unitarily equivalent representations. On L²(T, D²dt), the
operator -Δ_T is CONJUGATED by D to give -Δ_{1/2}^{(T,D²dt)} = D^{-1}(-Δ_T)D
(on L²(T, dt)). And by HC, D^{-1}(-Δ_T)D = -Δ_G|_class.

So Thm M3.1 says: *after unitary transformation* (the isomorphism L²(G)_class ≅
L²(T, D²dt)), the operator -Δ_G becomes -Δ_T. This is a UNITARY EQUIVALENCE, not
an operator identity on a single L² space.

**Verdict: Thm M3.1 is CORRECT** as stated in the HC notebook.

## §2. OQ-SD-1: Heat Kernel on SU(N) for N > 2

### §2.1. The Question

**OQ-SD-1** (BB4 §7): Does the exponential structure a_k(−Δ_g) = (R/6)^k/k! for all k
on S³ ≅ SU(2) extend to SU(N) for N ≥ 3?

Equivalently: on SU(N) with bi-invariant Killing metric, does
Z₀(t) = (4πt)^{−d/2} Vol(SU(N)) · exp(t·R/6) hold up to exponentially small corrections?

### §2.2. Setup

SU(N): d = N²−1, Ricci scalar R = N(N²−1) (Killing normalization, |α_long|² = 2).
- SU(2): d=3, R=6 ✓
- SU(3): d=8, R=24
- SU(N): V_HD = -|ρ|² = -N(N²-1)/24 (by FdV)

Eigenvalues of −Δ_G: C₂(λ) = |λ+ρ|² − |ρ|² for λ ∈ Λ⁺.
Degeneracy: (dim Vλ)².

### §2.3. Why SU(2) is special

On SU(2): label irreps by n = dim V_λ ≥ 1. Then dim V_λ = n and C₂(λ) = n²−1.
Heat trace: Z₀(t) = Σ_{n≥1} n² e^{−t(n²−1)} = e^t · Σ n² e^{−tn²}.

The sum Σ n² e^{−tn²} = −d(θ₃)/dt. The Jacobi theta inversion (Poisson summation)
gives this sum in closed form with ONLY exponentially small corrections. This is the
reason a_k = 1/k! for ALL k — no polynomial subleading terms exist.

**The key:** dim(V_n) = n is a DEGREE-1 polynomial in n, so (dim V_n)² = n² is
degree-2. The eigenvalue n²−1 is also degree-2. Their ratio is asymptotically 1,
making the theta function the natural generating function.

### §2.4. SU(3) dimension and eigenvalue structure

For SU(3): label irreps by (a,b) with a,b ≥ 0.
- dim V_{(a,b)} = (a+1)(b+1)(a+b+2)/2   [degree-3 polynomial]
- C₂(a,b) = a²+ab+b²+3a+3b             [degree-2 polynomial, using |α|²=2]

The (dim V)² = [(a+1)(b+1)(a+b+2)/2]² is a DEGREE-6 polynomial in (a,b).
The eigenvalue C₂(a,b) is degree-2.

The heat trace sum over the 2D lattice (a,b) ≥ 0 with these weights does NOT reduce
to a product of theta functions. By Euler-Maclaurin on the 2D lattice, there will be
polynomial corrections in t^k for k ≥ 1, i.e., a₂, a₃, ... ≠ 0.

### §2.5. The Weyl tensor obstruction

On S³ ≅ SU(2): Weyl tensor C_{abcd} = 0 (3D geometry, constant curvature).
On SU(3) (d=8): the Weyl tensor is NONZERO (it's a symmetric space of rank 2,
not constant curvature). This implies:

a₂(−Δ; SU(3)) contains a Kretschmann-Ricci term:
```
a₂ = ∫ [(Kret − Ric²)/180 + R²/72] dV    [bare Laplacian E=0, ΔR=0]
```
On SU(3): Kret ≠ Ric² (Weyl ≠ 0), so (Kret − Ric²)/180 ≠ 0.

For exponential structure: would need a₂/a₀ = (R/6)²/2 = 8.
But the Kret − Ric² contribution adds a nonzero term. It is extremely unlikely
(absent a miraculous cancellation) that a₂ = 8 · a₀ exactly.

### §2.6. Conjectured answer to OQ-SD-1

**Conjecture M4.1 (R28).** The exponential structure a_k(−Δ_g) = (R/6)^k/k! for all k
holds on a compact Lie group G (with bi-invariant metric) if and only if G ≅ SU(2) (or
a quotient with the same local geometry, i.e., S³, SO(3), lens spaces).

**Evidence:**

3. The Bernoulli vanishing (KL all-orders): the Conjecture CMP11.2 (universal d(d−1)(d−3)

**What holds for all G:** a₁(−Δ) = R/6 always (E=0). Only a₁ is universal.
Higher a_k depend on the global Weyl and Riemann curvature structure.
