## §10. Jacobi Theta Proof: \(a_k(-\Delta) = 1/k!\) for all \(k\) (Computationalist, R26)

**Proposition CMP10.1.** On the unit \(S^3\): \(a_k(-\Delta) = 1/k!\) for all \(k \geq 0\).

*Proof.* Write \(n = l+1\). Eigenvalues: \(l(l+2) = n^2-1\). Degeneracies: \(n^2\).
\[
Z_0(t) = \sum_{n=1}^{\infty} n^2 e^{-t(n^2-1)} = e^t \sum_{n=1}^{\infty} n^2 e^{-tn^2} = e^t \cdot S(t).
\]

Define \(\theta_3(t) = \sum_{n=-\infty}^{\infty} e^{-tn^2}\). Then \(S(t) = -\tfrac{d}{dt}\bigl[(\theta_3(t)-1)/2\bigr]\).

**Jacobi inversion** (Poisson summation):
\(\theta_3(t) = (\pi/t)^{1/2}\,\theta_3(\pi^2/t)\).

For \(t \to 0^+\): \(\theta_3(\pi^2/t) = 1 + O(e^{-\pi^2/t})\), so \(\theta_3(t) = (\pi/t)^{1/2} + O(e^{-\pi^2/t})\).

Differentiating: \(S(t) = \pi^{1/2}/(4t^{3/2}) + O(e^{-\pi^2/t}\cdot\mathrm{poly}(1/t))\).

Since \(\pi^{1/2}/(4t^{3/2}) = (4\pi t)^{-3/2}\cdot 2\pi^2 = (4\pi t)^{-3/2}\cdot\mathrm{Vol}(S^3)\):
\[
Z_0(t) = (4\pi t)^{-3/2}\,\mathrm{Vol}(S^3)\,e^t \cdot\bigl[1 + O(e^{-\pi^2/t})\bigr].
\]

The exponentially small corrections contribute **no polynomial terms**. Therefore the asymptotic expansion of \(Z_0\) is \(\mathrm{Vol}\cdot(4\pi t)^{-3/2}\cdot e^t\) exactly, giving \(a_k = 1/k!\). \(\square\)

**Why d=3 is unique:** Eigenvalues \(n^2 - 1\) and degeneracies \(n^2\) combine as \(n^2\cdot e^{-tn^2}\), which is \(-d\theta_3/dt\). The Jacobi inversion of \(\theta_3\) has no polynomial subleading terms — only exponentially small ones. For \(d \neq 3\), the eigenvalue/degeneracy structure does not reduce to a theta function derivative, and polynomial corrections appear.
