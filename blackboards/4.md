## §3. d=3 Kretschner Identity (Weyl=0)

**Theorem C4.1.** On any 3-dimensional Riemannian manifold:
\[
R_{abcd}R^{abcd} = 4R_{ab}R^{ab} - R^2.
\]

**Proof sketch.** Choose an orthonormal frame; let \(R_{ab} = \mathrm{diag}(r_1, r_2, r_3)\) in that frame. From the Weyl decomposition \(C_{abcd} = 0\) in \(d=3\):
\[
R_{1212} = \tfrac{r_1+r_2-r_3}{2}, \quad R_{1313} = \tfrac{r_1-r_2+r_3}{2}, \quad R_{2323} = \tfrac{-r_1+r_2+r_3}{2}.
\]
Kretschner:
\[
R_{abcd}R^{abcd} = 4(R_{1212}^2 + R_{1313}^2 + R_{2323}^2).
\]
Expanding:
\[
= (r_1{+}r_2{-}r_3)^2 + (r_1{-}r_2{+}r_3)^2 + ({-}r_1{+}r_2{+}r_3)^2
= 4(r_1^2+r_2^2+r_3^2) - (r_1+r_2+r_3)^2
= 4R_{ab}R^{ab} - R^2. \quad\square
\]


## §5. The Factor (d-3): Algebraic Decomposition

**Vassilevich convention (explicit):** \(P = -(g^{\mu\nu}\nabla_\mu\nabla_\nu + E)\), so \(E = -V_{\mathrm{HD}} = +R/6\) for the half-density scalar. The Gilkey formula uses \(+E\) (not \(+V\)):
\[
a_1 = \tfrac{1}{6}R + E = \tfrac{1}{6}R + R/6 = R/3 \quad \text{[generic operator]};\quad a_1(\Delta_{1/2}) = \tfrac{1}{6}R - \tfrac{1}{6}R = 0.
\]
In \(V\)-notation (\(V = V_{\mathrm{HD}} = -R/6\)): \(a_1 = R/6 + V = 0\). Same algebra; sign convention differs.

On \(S^d\), the Kretschner–Ricci² difference:
\[
R_{abcd}R^{abcd} - R_{ab}R^{ab} = \frac{2R^2}{d(d-1)} - \frac{R^2}{d} = \frac{R^2(3-d)}{d(d-1)}.
\]

**This IS the source of the \((d-3)\) factor.** Substituting into the Gilkey formula (Vassilevich, with \(E = +R/6\)):
\[
a_2(\Delta_{1/2}; S^d) = \underbrace{\frac{R^2(3-d)}{180\,d(d-1)}}_{\text{Kretschner–Ricci}^2} + \underbrace{\frac{R^2}{72} - \frac{R^2}{36} + \frac{R^2}{72}}_{\text{E-dependent terms} = 0} = \frac{R^2(3-d)}{180\,d(d-1)} + 0.

The \(E\)-dependent terms cancel independently (Vassilevich notation, \(E=+R/6\)):
\[
\frac{1}{72}R^2 - \frac{1}{6}R\cdot\frac{R}{6} + \frac{1}{2}\left(\frac{R}{6}\right)^2 = \frac{R^2}{72}(1 - 2 + 1) = 0 \quad \text{(SymPy verified for all }d\text{)}.
\]
Equivalently in \(V\)-notation (\(V = -R/6\)): \(R^2/72 + R(-R/6)/6 + (-R/6)^2/2 = 0\). Same cancellation.

**Conclusion:**
\[
a_2(\Delta_{1/2}; S^d) = \frac{R^2(3-d)}{180\,d(d-1)} = -\frac{d(d-1)(d-3)}{180} \quad\text{(with }R = d(d-1)\text{ on unit }S^d\text{)}.
\]
