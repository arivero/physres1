## §7. TG-Q11: Lackman PI=Berezin Forces Half-Density Coefficient System

**Task:** Does Lackman's PI=Berezin axiomatization (arXiv:2410.02739), applied to Riemannian manifolds with the heat kernel as propagator, force the half-density coefficient system? Does g^{1/4} appear in Berezin quantization on curved spaces?

**Answer:** YES. The mechanism is purely algebraic and follows from three facts.

### §7.1. The Composition Identity

The heat kernel K_t(x,y) on (M,g) satisfies the semigroup/composition property (Lackman's central axiom):

    K_{t+s}(x,y) = int_M K_t(x,z) K_s(z,y) dvol_g(z)

where dvol_g = |g|^{1/2} d^d z is the Riemannian volume element.

Define the half-density kernel:

    K~_t(x,y) = |g(x)|^{1/4} K_t(x,y) |g(y)|^{1/4}

Then:

    int K~_t(x,z) K~_s(z,y) d^d z
      = int |g(x)|^{1/4} K_t(x,z) |g(z)|^{1/4} * |g(z)|^{1/4} K_s(z,y) |g(y)|^{1/4} d^d z
      = |g(x)|^{1/4} |g(y)|^{1/4} int K_t(x,z) K_s(z,y) |g(z)|^{1/2} d^d z
      = |g(x)|^{1/4} |g(y)|^{1/4} K_{t+s}(x,y)
      = K~_{t+s}(x,y)

The half-density kernel composes with **flat (Lebesgue) measure** — no dvol_g needed.

### §7.2. Why g^{1/4} Is Forced

On the pair groupoid M x M, Connes (§II.5) shows that the unique measure-independent convolution algebra uses half-density coefficients. The two |g|^{1/4} factors at the intermediate point z combine to give |g(z)|^{1/2} = dvol_g(z)/d^d z, absorbing the Riemannian measure into the kernel.

This is not a choice — it is the DEFINITION of the half-density bundle section in coordinates:

    K_t in Gamma(|Omega_x|^{1/2} tensor |Omega_y|^{1/2})

In coordinates: K_t(x,y)|d^d x|^{1/2}|d^d y|^{1/2} = (|g(x)||g(y)|)^{1/4} K_t(x,y) |d^d x|^{1/2}|d^d y|^{1/2}.

### §7.3. Connection to Lackman's Axioms

Lackman's axioms use an abstract measure d mu. On (M,g), d mu = dvol_g. The composition axiom:

    PI(x->z) = int PI(x->y) PI(y->z) d mu(y)

forces |g|^{1/2} in the intermediate measure. This factors symmetrically as |g|^{1/4} x |g|^{1/4}, one factor per kernel leg. Lackman does not mention half-densities explicitly because his formulation absorbs them into the measure choice.

The Berezin quantization structure (coherent states, resolution of identity) maps directly:
- Berezin coherent state |x> with <x|y> = K_t(x,y)
- Resolution: 1 = int |x><x| d mu(x) with d mu = c(t) dvol_g
- Half-density version: |x>~ = |g(x)|^{1/4}|x>, giving <x|y>~ = K~_t(x,y)
- Resolution: 1 = int |x>~<x|~ d^d x / c(t) — flat measure, no dvol_g

### §7.4. Consequence: a_1 = 0 Universally

K~ satisfies the heat equation for Delta_{1/2} = |g|^{1/4} Delta_g |g|^{-1/4}, whose potential is V_HD = -R/6. The Seeley-DeWitt expansion gives:

    a_1(Delta_{1/2}) = R/6 + V_HD = R/6 - R/6 = 0

This is universal on ALL (M,g) — Theorem M4.1. The half-density coefficient system (a~_0=1, a~_1=0, ...) is forced by the composition axiom.

## §8. P12.2 Sharp Constant: C = 1 (not C = 2)

<!-- Computationalist: R30, addresses F5-10.6 (sev-3) -->

**Task:** The critic's audit F5-10.6 notes the paper's C=2 is valid but not sharp, and suggests C=3/2 may be achievable. Can we prove a tighter bound?

**Result:** The sharp constant is **C = 1**, tighter than both C=2 (paper) and C=3/2 (critic suggestion).

### §8.1. Closed-form bound

From the three-term identity (P12.2 proof sketch), the total bound with a = Mt, b = Ms is:

    f(a,b) = (e^a - 1 - a)(1 + b) + e^a(e^b - 1 - b) + (e^{a+b} - 1 - (a+b))

**Lemma CMP12.1:** f(a,b) = 2e^{a+b} - 2 - 2a - 2b - ab.

*Proof:* Direct expansion of the three terms. SymPy-verified (tmp/p12_2_sharp_constant_v2.py).

### §8.2. Proof that f(a,b) <= (a+b)^2 e^{a+b}

Define g(a,b) = (a+b)^2 e^{a+b} - f(a,b) = [(a+b)^2 - 2]e^{a+b} + 2 + 2(a+b) + ab.

Since ab >= 0, g(a,b) >= h(a+b) where h(u) = (u^2 - 2)e^u + 2 + 2u.

**Claim:** h(u) >= 0 for all u >= 0, with equality only at u = 0.

*Proof:* h(0) = 0, h'(0) = 0, h''(0) = 0, h'''(u) = (u^2 + 6u + 4)e^u > 0 for u >= 0. Triple integration from 0 gives h(u) > 0 for u > 0. QED.

### §8.3. Leading-order structure

For small Mt, Ms: f(a,b) ~ M^2(t^2 + ts + s^2), so the ratio f/[M^2(t+s)^2 e^{M(t+s)}] approaches (t^2+ts+s^2)/(t+s)^2 = 1 - ts/(t+s)^2, which ranges from 3/4 (t=s) to 1 (t/s -> 0 or infinity). The supremum is 1, attained in the limit.

### §8.4. Numerical verification

Script tmp/p12_2_sharp_constant_v2.py: 500x400 grid scan, max ratio = 0.984 at a=0.012, b=0.0001. The ratio approaches 1 from below as both parameters approach 0 asymmetrically.

### §8.5. Patch recommendation

Replace "(e.g. C=2)" with "(e.g. C=1)" in P12.2, line 1947. The proof is elementary (§8.2) and self-contained. The bound is unchanged in form, only the constant improves.
