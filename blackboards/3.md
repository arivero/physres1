## §2. Setup and Notation

- G compact semisimple, dim G = d, rank r
- T: maximal torus with Lie algebra t ⊆ g
- Φ⁺: positive roots; m_α: multiplicity (m_α = 1 for simply-laced, e.g. SU(N))
- ρ = (1/2) ∑_{α∈Φ⁺} m_α · α (Weyl vector; element of t* in metric-dual norm)

- D(H) = ∏_{α∈Φ⁺} |e^{α(H)/2} − e^{−α(H)/2}|^{m_α} (Weyl denominator, H ∈ t)
- Λ^+: dominant integral weights; V_λ: irrep with highest weight λ
- C_2(λ) = |λ+ρ|²_g − |ρ|²_g (quadratic Casimir, Freudenthal formula)

## §3. Three Key Facts

**Fact 1 (Casimir eigenvalue).**
\[ \mathrm{Spec}_{L^2(G)}(-\Delta_G) = \{C_2(\lambda) = |\lambda+\rho|^2 - |\rho|^2 : \lambda \in \Lambda^+\},\quad \mathrm{mult} = (\dim V_\lambda)^2 \]

**Fact 2 (Weyl denominator as eigenfunction).**
\[ (-\Delta_T) D = |\rho|^2 \cdot D \]
Proof: D = A_ρ = ∑_{w∈W} det(w) e^{w(ρ)(·)} is a sum of toral exponentials with weights w(ρ), all of norm |ρ|². Since −ΔT acts by |μ|² on e^{μ(·)}, and |w(ρ)|² = |ρ|² for all w:
\[ (-\Delta_T) D = |\rho|^2 D. \]

**Fact 3 (HC radial formula).**
For class functions f on G (viewed as functions of H ∈ t via f(e^H)):
\[ (-\Delta_G f)(e^H) = D(H)^{-1}(-\Delta_T)(D(H) \cdot f(e^H)) \]
Reference: Helgason, Groups and Geometric Analysis (1984), Ch. II §3.

## §4. Harish-Chandra Isospectrality

**Lemma M3.2.** The half-density Laplacian on G, restricted to class functions, satisfies:
\[ (-\Delta_{1/2}^G)\big|_{\mathrm{class}} = D^{-1/2}(-\Delta_T) D^{1/2} \]
as operators on L²(G)_{class} ≅ L²(T)^W.

**Proof of Lemma M3.2.**
(i) By Weyl integration formula: |g_G|^{1/2}|_T dH = C · D(H)^2 dH (where C = (vol G/T)·|W|^{−1}).
(ii) Hence |g_G|^{1/4}|_T = C^{1/2} · D(H) for regular H.
(iii) On class functions, −Δ_{1/2}^G = −|g|^{1/4} ΔG |g|^{−1/4} = −D · ΔG · D^{−1} (class functions).
(iv) Using HC (Fact 3) on the class function h = D^{−1} f:
    \[(−\Delta_G h)(e^H) = D^{-1}(-\Delta_T)(D · h) = D^{-1}(-\Delta_T)(D · D^{-1} f) = D^{-1}(-\Delta_T)f\]
Wait — this gives −ΔG·D^{−1}f = D^{−1}(−ΔT)f, so −D·ΔG·D^{−1} f = D · D^{−1}(−ΔT)f = (−ΔT)f.

**ISSUE (boundary condition):** D^{−1} is singular at Weyl chamber walls (D = 0 there). The HC formula requires smooth class functions. Application to D^{−1} f requires f to vanish where D vanishes, i.e., f ∈ W-antisymmetric functions. □

## §7. Correcting the Identification

**The Weyl integration formula** gives:
\[\int_G f(g)\,dg = \frac{1}{|W|}\int_T D(t)^2 \left(\int_{G/T} f(k^{-1}tk)\,dk\right)dt\]

So L²(G)_{class} with Haar measure ↔ L²(T, D²dt/|W|)^{W,+}.

**The flat L²(T, dt) vs weighted L²(T, D²dt):**
These are DIFFERENT Hilbert spaces. The identification changes the inner product and hence the spectrum.

**Half-density on G viewed on T:**
With the weighted measure D²dt on T, the half-density of T is D (the square root of the density D²). The half-density Laplacian on (T, D²dt) is:
\[-\Delta_{1/2}^{(T,D^2dt)} = D^{-1}(-\Delta_T)D = -\Delta_T + 2\nabla(\log D)\cdot\nabla + |\rho|^2\]
(using Fact 2: D^{−1}(−ΔT D) = |ρ|²).

**This equals −ΔG|_{class}** (by HC Fact 3). ✓

So: −ΔG|_{class} = −Δ_{1/2}^{(T,D²dt)}.

The Laplacian on G restricted to class functions IS the half-density Laplacian on (T, D²dt). This is the geometric content of the HC formula.
