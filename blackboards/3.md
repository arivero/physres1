## §2. Setup and Notation

- G compact semisimple, dim G = d, rank r
- T: maximal torus with Lie algebra t ⊆ g
- Φ⁺: positive roots; m_α: multiplicity (m_α = 1 for simply-laced, e.g. SU(N))
- ρ = (1/2) ∑_{α∈Φ⁺} m_α · α (Weyl vector; element of t* in metric-dual norm)
- |ρ|²_g = metric-dual norm of ρ (BB0 §12: |ρ|²_g = dim(G)·h∨/24 for g = −2Tr)
- D(H) = ∏_{α∈Φ⁺} |e^{α(H)/2} − e^{−α(H)/2}|^{m_α} (Weyl denominator, H ∈ t)
- Λ^+: dominant integral weights; V_λ: irrep with highest weight λ
- C_2(λ) = |λ+ρ|²_g − |ρ|²_g (quadratic Casimir, Freudenthal formula)

## §3. Three Key Facts

**Fact 1 (Casimir eigenvalue).**
\[ \mathrm{Spec}_{L^2(G)}(-\Delta_G) = \{C_2(\lambda) = |\lambda+\rho|^2 - |\rho|^2 : \lambda \in \Lambda^+\},\quad \mathrm{mult} = (\dim V_\lambda)^2 \]

**Fact 2 (Weyl denominator as eigenfunction).**
\[ (-\Delta_T) D = |\rho|^2 \cdot D \]
Proof: D = A_ρ = ∑_{w∈W} det(w) e^{w(ρ)(·)} is a sum of toral exponentials with weights w(ρ), all of norm |ρ|². Since −ΔT acts by |μ|² on e^{μ(·)}, and |w(ρ)|² = |ρ|² for all w:
\[ (-\Delta_T) D = |\rho|^2 D. \]

**Fact 3 (HC radial formula).**
For class functions f on G (viewed as functions of H ∈ t via f(e^H)):
\[ (-\Delta_G f)(e^H) = D(H)^{-1}(-\Delta_T)(D(H) \cdot f(e^H)) \]
Reference: Helgason, Groups and Geometric Analysis (1984), Ch. II §3.

## §4. Harish-Chandra Isospectrality

**Lemma M3.2.** The half-density Laplacian on G, restricted to class functions, satisfies:
\[ (-\Delta_{1/2}^G)\big|_{\mathrm{class}} = D^{-1/2}(-\Delta_T) D^{1/2} \]
as operators on L²(G)_{class} ≅ L²(T)^W.

**Proof of Lemma M3.2.**
(i) By Weyl integration formula: |g_G|^{1/2}|_T dH = C · D(H)^2 dH (where C = (vol G/T)·|W|^{−1}).
(ii) Hence |g_G|^{1/4}|_T = C^{1/2} · D(H) for regular H.
(iii) On class functions, −Δ_{1/2}^G = −|g|^{1/4} ΔG |g|^{−1/4} = −D · ΔG · D^{−1} (class functions).
(iv) Using HC (Fact 3) on the class function h = D^{−1} f:
    \[(−\Delta_G h)(e^H) = D^{-1}(-\Delta_T)(D · h) = D^{-1}(-\Delta_T)(D · D^{-1} f) = D^{-1}(-\Delta_T)f\]
Wait — this gives −ΔG·D^{−1}f = D^{−1}(−ΔT)f, so −D·ΔG·D^{−1} f = D · D^{−1}(−ΔT)f = (−ΔT)f.

**ISSUE (boundary condition):** D^{−1} is singular at Weyl chamber walls (D = 0 there). The HC formula requires smooth class functions. Application to D^{−1} f requires f to vanish where D vanishes, i.e., f ∈ W-antisymmetric functions. □

## §5. Correct Formulation: W-Antisymmetric Route

**Observation.** The natural domain for the HC isospectrality is W-antisymmetric functions on T.

Define:
- L²(T)^{W,+}: W-symmetric (class functions on G, restricted to T)
- L²(T)^{W,−}: W-antisymmetric (sections with det(w)-twisted symmetry)

**Key isomorphism:** The map
\[\Psi: L^2(T)^{W,+} \xrightarrow{\ \cdot D\ } L^2(T)^{W,-}\]
is an isometric isomorphism (up to the constant C).

**Eigenvalues of −ΔT on L²(T)^{W,−}:**
Orthonormal basis: A_{λ+ρ} = ∑_{w∈W} det(w) e^{w(λ+ρ)(·)}, with eigenvalue |λ+ρ|².

**Eigenvalues of −ΔT on L²(T)^{W,+} = −ΔT · D^{−1} · [L²^{W,−}] ·D:**
The map D^{−1}: L²^{W,−} → L²^{W,+} conjugates −ΔT to:
\[D^{-1}(-\Delta_T)D = -\Delta_T + 2\nabla(\log D)\cdot\nabla + \underbrace{D^{-1}(-\Delta_T D)}_{= |\rho|^2} = -\Delta_T + 2\nabla(\log D)\cdot\nabla + |\rho|^2\]

This equals −ΔG|_{class} (by Fact 3 applied to the class function f: the full operator is −ΔT + [gradient term involving D'/D] + |ρ|²). The gradient term is the "drift" term in the HC radial formula. ✓

## §6. The Spectral Argument (Main Proof)

**Proposition M3.3.**
\[ \mathrm{Spec}(-\Delta_{1/2}^G)\big|_{\mathrm{class}} = \{|\lambda+\rho|^2 : \lambda \in \Lambda^+\} \]

**Proof.**
(i) The operator D^{−1/2}(−ΔT)D^{1/2} on L²(T)^{W,+} is unitarily equivalent to −ΔT on L²(T)^{W,−} via:
\[D^{1/2} \circ \bigl(D^{-1/2}(-\Delta_T)D^{1/2}\bigr) \circ D^{-1/2} = -\Delta_T\]
(trivial algebraic identity; requires D^{1/2} invertible, i.e., away from chamber walls).

(ii) Spectrum of −ΔT on L²(T)^{W,−}: {|λ+ρ|² : λ ∈ Λ+}, with eigenfunctions A_{λ+ρ}.

(iii) Therefore Spec(D^{−1/2}(−ΔT)D^{1/2}) = {|λ+ρ|² : λ ∈ Λ+}.

(iv) **Claim:** −Δ_{1/2}^G|_{class} = D^{−1/2}(−ΔT)D^{1/2} as a self-adjoint operator.

**Proof of claim:** In L²(G) with Haar measure, using the isometry Ψ:
The half-density Laplacian −Δ_{1/2}^G = |g|^{1/4}(−ΔG)|g|^{−1/4}. On class functions (L²(G)_{class}), identified with L²(T)^{W,+} via Weyl integration, the density factor |g|^{1/4}|_T = C^{1/2}D (Step (ii) of Lemma M3.2). Thus:
\[-\Delta_{1/2}^G\big|_\text{class} = C^{1/2} D \cdot (-\Delta_G) \cdot C^{-1/2} D^{-1}\big|_\text{class}\]
Using HC Fact 3:
\[= C^{1/2} D \cdot D^{-1}(-\Delta_T) \cdot C^{-1/2} D^{-1} \cdot D = D^{1/2}(-\Delta_T)D^{-1/2}\]

Wait: C^{1/2} D · D^{-1}(-ΔT) · C^{-1/2} · ???

Let me redo this carefully. The half-density Laplacian:
\[-\Delta_{1/2}^G f = -|g|^{1/4}\Delta_G(|g|^{-1/4} f)\]
On T with h = |g|^{−1/4}f = C^{−1/2}D^{−1}f:
\[= -C^{1/2} D \cdot \Delta_G(C^{-1/2} D^{-1} f)\]
\[= -C^{1/2} D \cdot D^{-1}(-\Delta_T)(D \cdot C^{-1/2}D^{-1}f) \quad\text{(HC with class fn }g=C^{-1/2}D^{-1}f\text{)}\]

## §7. Correcting the Identification

**The Weyl integration formula** gives:
\[\int_G f(g)\,dg = \frac{1}{|W|}\int_T D(t)^2 \left(\int_{G/T} f(k^{-1}tk)\,dk\right)dt\]

So L²(G)_{class} with Haar measure ↔ L²(T, D²dt/|W|)^{W,+}.

**The flat L²(T, dt) vs weighted L²(T, D²dt):**
These are DIFFERENT Hilbert spaces. The identification changes the inner product and hence the spectrum.

**Half-density on G viewed on T:**
With the weighted measure D²dt on T, the half-density of T is D (the square root of the density D²). The half-density Laplacian on (T, D²dt) is:
\[-\Delta_{1/2}^{(T,D^2dt)} = D^{-1}(-\Delta_T)D = -\Delta_T + 2\nabla(\log D)\cdot\nabla + |\rho|^2\]
(using Fact 2: D^{−1}(−ΔT D) = |ρ|²).

**This equals −ΔG|_{class}** (by HC Fact 3). ✓

So: −ΔG|_{class} = −Δ_{1/2}^{(T,D²dt)}.

The Laplacian on G restricted to class functions IS the half-density Laplacian on (T, D²dt). This is the geometric content of the HC formula.

## §8. Main Theorem: HC Proof

**Theorem M3.1 (HC Proof, precise statement).**

On the Lie group G with bi-invariant metric g, identified with (T, D²dt/|W|) for class functions:

\[\boxed{-\Delta_{1/2}^G\big|_\text{class} = -\Delta_T \quad \text{on } L^2(T,\,D^2\,dt/|W|)^{W,+}}\]

**Proof.**
The half-density measure on (T, D²dt) is (D²)^{1/2}dt = Ddt. The half-density Laplacian on (T, D²dt) is:
\[-\Delta_{1/2}^{(T,D^2dt)} = D^{-1}(-\Delta_T)D = -\Delta_G|_\text{class} \quad\text{(HC)}\]

The **ordinary Laplacian** −ΔT on (T, dt) has eigenvalues {|μ|² : μ ∈ Λ*}.
The **half-density Laplacian** on (T, D²dt) = −Δ_{1/2}^{(T,D²dt)} has eigenvalues {|λ+ρ|² − |ρ|² : λ ∈ Λ+} (since it = −ΔG|_{class} by HC). ✓

**Extracting V_HD:**

\[V_\mathrm{HD} = (-\Delta_{1/2}^G) - (-\Delta_G) = (-\Delta_G|_\text{class}) - (-\Delta_G|_\text{class}) = 0 \text{ ???}\]

No: the issue is that −Δ_{1/2}^G and −ΔG act on DIFFERENT Hilbert spaces (different half-density bundles). V_HD is defined as:
\[V_\mathrm{HD} = -|g|^{1/4}\Delta_G|g|^{-1/4} \quad (\text{as a multiplication operator})\]

On G, since V_HD is constant (Prop M0.1), it suffices to identify the SPECTRAL SHIFT.

## §10. Resolution: Direct HC Computation of V_HD

**The correct HC proof** directly computes V_HD via:

**Lemma M3.5.** In the coordinate system {H ∈ t (regular), k ∈ G/T} on G, with metric g:
\[|g(H,k)|^{-1/4} \cdot \Delta_G(|g|^{-1/4})\big|_\text{radial part} = -D(H)^{-1/2}\Delta_T(D(H)^{1/2})\]

**Proof:** The full G Laplacian in (H, k) coordinates decomposes as:
\[\Delta_G = \Delta_T + (\text{G/T part}) + (\text{cross terms})\]
For bi-invariant metrics, cross terms vanish (H and k are orthogonal). The radial (T) part in the density-weighted form gives:
\[\Delta_G|_\text{radial} = D^{-1}\Delta_T D\]
(HC Fact 3 in differential-operator form).

Therefore the radial part of |g|^{−1/4}ΔG(|g|^{−1/4}) is:
\[|g|^{-1/4}\cdot D^{-1}\Delta_T D \cdot |g|^{-1/4} = D^{-1/2} \cdot D^{-1}\Delta_T D \cdot D^{-1/2}\]
\[= D^{-3/2}\Delta_T(D \cdot D^{-1/2}) = D^{-3/2}\Delta_T(D^{1/2})\]

**Using** −ΔT D = |ρ|² D and the identity:
\[-\Delta_T(D^{1/2}) = \frac{1}{2}D^{-1/2}(-\Delta_T D) - \frac{1}{4}D^{-3/2}|\nabla_T D|^2 + D^{1/2}\frac{|\nabla_T D|^2}{4D^2}\]

\[V_\mathrm{HD} = -D^{-1/2}(-\Delta_T)D^{1/2}\Big|_{H\to 0}\]

Specifically: D(H) = D_\text{lin}(H) · (1 − (1/24)∑_α m_α α(H)² + O(H⁴)) where D_\text{lin}(H) = ∏_α |α(H)|^{m_α}.

For the computation of V_HD = −D^{−1/2}(−ΔT)D^{1/2}|_0, the singularity of D at 0 means this is evaluated as a LIMIT, which exactly reduces to the RNC expansion. The HC formula gives the same R/6 result by the singularity analysis.
